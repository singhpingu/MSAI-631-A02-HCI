# MSAI-631-A02-HCI

Course repository for MSAI-631-A02 Artificial Intelligence for Human-Computer Interaction.

## Development environment

This repository contains a reproducible Python 3.12 development environment for GitHub Codespaces. The container installs the dependencies in `requirements.txt` and forwards port 7860 for the Gradio application.

## Run the Hello HCI application

```bash
python app.py
```

Open the forwarded port 7860 to use the interface.
